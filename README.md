# ai_prod

Инструменты для отслеживания клинических исследований antibody-drug conjugates
(ADC) в онкологии: сбор данных с ClinicalTrials.gov и агент конкурентной
разведки на Claude API поверх этих данных.

## Состав проекта

- **`adc_trials_fetch.py`** — обёртка над [ClinicalTrials.gov API v2](https://clinicaltrials.gov/data-api/api).
  Ищет исследования ADC в онкологии, обновлённые за последние N дней (по
  умолчанию 90), листает результаты через `nextPageToken` и дедуплицирует по
  `NCTId`. Запросы к API идут с ретраями на таймауты/сетевые сбои
  (экспоненциальный бэкофф). Доступ к API бесплатный, авторизация не нужна.

- **`adc_agent.py`** — агент конкурентной разведки на Claude API с двумя
  инструментами:
  - `fetch_adc_trials` — оборачивает `fetch_all_adc_updates()`, данные из
    реестра ClinicalTrials.gov (статус, фаза, спонсор, даты);
  - `web_search` — встроенный серверный tool Claude API
    (`web_search_20250305`), для новостей и пресс-релизов о сделках,
    партнёрствах и регуляторных решениях по ADC, которых в реестре
    клинических испытаний нет и быть не может.

  Системный промпт задаёт роль аналитика и жёсткие guardrails: каждый факт в
  сводке обязан ссылаться на источник — `[Реестр]` (NCT ID + ссылка) или
  `[Веб]` (URL + дата публикации) — без смешивания источников в одном
  пункте; домыслы явно помечаются как предположения, а не подаются как
  факты.

## Установка

```bash
pip install anthropic python-dotenv requests
```

## Настройка

Для `adc_agent.py` нужен ключ Anthropic API. Создайте `.env` рядом со
скриптами (файл в `.gitignore`, в репозиторий не попадает):

```
ANTHROPIC_API_KEY=sk-ant-...
```

`adc_trials_fetch.py` авторизации не требует.

## Запуск

Сбор сырых данных по ADC-исследованиям:

```bash
python3 adc_trials_fetch.py
```

Аналитическая сводка через агента (внутри вызывает `adc_trials_fetch.py`):

```bash
python3 adc_agent.py
```

Второй скрипт делает потоковый (streaming) запрос к Claude — на широкой
выборке исследований сводка может генерироваться несколько минут.

## Модель

`adc_agent.py` использует `claude-opus-5`. При необходимости модель можно
поменять, изменив константу `MODEL` в начале файла.
